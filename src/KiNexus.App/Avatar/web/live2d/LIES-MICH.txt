Hier gehört die Datei live2dcubismcore.min.js hinein (Cubism Core von Live2D).

So bekommst du sie:
1. Geh auf https://www.live2d.com/en/sdk/download/web/
2. Lies und akzeptiere die Lizenz und lade das "Cubism SDK for Web" herunter (gratis).
3. Entpacke das ZIP. Die Datei liegt im Ordner Core/live2dcubismcore.min.js
4. Kopier sie in diesen Ordner (live2d/) und lade das Testpanel neu.

Statt die Datei hierhin zu kopieren, kannst du sie auch im Panel mit
"Cubism Core wählen" auswählen. Dann speichert sie der Browser für das nächste Mal.
